# Media library

Real photos from the shop for Bishops Chamblee posts. These are not queued to post: when one is picked for a post, it gets copied into `to-post/` with its caption.

- `originals/`: full resolution (2400x3600, 2:3). Too tall for an Instagram feed post as is.
- `feed-4x5/`: cropped to 1080x1350 (4:5), ready for feed posts and carousels.
